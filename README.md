# محترف التسعير — Smart Pricing Pro (v1.0)

برنامج تسعير احترافي للتجار وأصحاب المشاريع الصغيرة في مصر.
يعمل **بالكامل بدون إنترنت**، بدون حسابات، بدون قاعدة بيانات، وبدون أي خدمات خارجية.

المطور: **Mahmoud Mansour**
العملة: الجنيه المصري (EGP) — الواجهة: عربية بالكامل (RTL)

---

## الأدوات المتوفرة

1. حاسبة تسعير المنتجات (مع تحليل ذكي: ممتاز / جيد / تحذير / خسارة)
2. حاسبة الأرباح
3. حاسبة الخصومات
4. حاسبة الضريبة (شامل / غير شامل)
5. حاسبة الشحن
6. حاسبة نقطة التعادل

مزايا إضافية: نسخ النتائج، الطباعة، حفظ PDF (من نافذة الطباعة → «حفظ كـ PDF»)، تصفير الحاسبة،
حفظ الحسابات في سجل محلي، حذف السجل، واستعادة آخر مدخلاتك تلقائياً عند إعادة الفتح.

---

## أين تُحفظ البيانات؟

كل البيانات تُحفظ داخل متصفح جهازك عبر **LocalStorage** بالمفاتيح:

- `spp.history.v1` — سجل الحسابات المحفوظة
- `spp.drafts.v1` — آخر مدخلات كل حاسبة (الاستعادة التلقائية)

لا يتم إرسال أي بيانات إلى أي سيرفر. لا يوجد تتبع ولا تحليلات ولا خطوط أو أيقونات خارجية —
كل الخطوط من نظام الجهاز وكل الأيقونات SVG محلية داخل المشروع.

## تشغيل المشروع محلياً (للمطور)

```bash
bun install     # أو npm install
bun run dev     # وضع التطوير
bun run build   # بناء نسخة الإنتاج
```

بعد البناء تجد ملفات النسخة النهائية داخل مجلد `.output/public`.

## طريقة التثبيت والاستخدام بدون إنترنت (للعميل)

الملف: `تعليمات-التشغيل-بدون-إنترنت.md`

باختصار:

1. افتح التطبيق مرة واحدة (بعد نشره أو تشغيله محلياً) وهو متصل بالإنترنت لأول مرة فقط.
2. من قائمة المتصفح اختر **«تثبيت التطبيق / Add to Home Screen»**.
3. بعد التثبيت يعمل التطبيق أوفلاين تماماً: أغلق الواي فاي وبيانات الهاتف وسيعمل كما هو.

## هيكل المشروع

```
public/
  manifest.webmanifest      # بيانات التطبيق للتثبيت (PWA)
  icons/app-icon.svg        # أيقونات SVG محلية
  favicon.ico
src/
  styles.css                # نظام التصميم (Dark + Glassmorphism)
  routes/__root.tsx         # الهيكل العام + RTL + بيانات الصفحة
  routes/index.tsx          # لوحة التحكم الرئيسية
  lib/pricing.ts            # كل معادلات الحسابات (محلية 100%)
  lib/history.ts            # السجل والحفظ التلقائي (LocalStorage)
  lib/offline.ts            # تسجيل Service Worker للعمل أوفلاين
  components/pricing/       # الحاسبات + الأيقونات + عناصر الواجهة
```

Service Worker يُنشأ آلياً عند البناء باسم `sw.js` (عبر vite-plugin-pwa) ويقوم بتخزين ملفات
التطبيق للعمل بدون إنترنت.

## معادلات الحساب

- إجمالي التكلفة = الشراء + الشحن + التغليف + الإعلان + مصروفات أخرى + عمولة المنصة
- سعر التعادل = التكاليف ÷ (1 − نسبة العمولة)
- سعر البيع المقترح = التكاليف × (1 + نسبة الربح) ÷ (1 − نسبة العمولة)
- صافي الربح = سعر البيع − إجمالي التكلفة
- هامش الربح = صافي الربح ÷ سعر البيع × 100
- ROI = صافي الربح ÷ إجمالي التكلفة × 100
- نقطة التعادل = التكاليف الثابتة ÷ (سعر البيع − تكلفة المنتج)
